# Code quality

You've "inherited" the `PlantStats.py` script from a colleague who has recently left your organistion for a round-the-world backpacking trip.

Apparently, the script computes some useful statistics for your annual report, from the data provided in `plants.csv`.

Your task is to:

1. run the script and work out if it's doing what it should do (hint: `python PlantStats.py plants.csv`)
2. take a look through the script and identify if it is doing what it should do.  Work with a colleague if you like.
   Consider the following dimensions of code quality: 
     - Readability: Can others understand what has been done?
     - Maintainability: Is the code structured in a modular and decoupled way?
     - Reliability & Correctness: Does the code do what it should?
     - Security: Is the software kept up to date? Are security flaws patched?
     - Efficiency & Performance: Does the code do what it does with a reasonable resource use?
3. Discuss in a group. What issues did you identify? What measures could help improve and enforce quality? Consider:
     - coding standards
     - code review
     - automated testing
     - static analysis
